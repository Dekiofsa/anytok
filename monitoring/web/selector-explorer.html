How the numbers and simulation work

“Harder” means a larger transfer gap: BPB with the new tokenizer minus BPB with the canonical tokenizer. The dot shows the average gap. A single text batch can score higher or lower than that average.

The methods cannot see all these dots. Each method chooses one tokenizer, receives its score on one batch, and updates what it has learned.

These are saved simulations. We start with 32 real measurements for each tokenizer, then apply the selected rule to make some tokenizers easier. No LM or hypernetwork is being trained on this page.

The slider moves in 25-step increments. The estimates shown are from before the displayed choice was made. The full-run chart includes all 20,000 choices.
